Tools

Agents call three tools over MCP. Everything else runs in one background process on your machine.

remember

Saves a bug's root cause, a convention or a decision with its reason. Near-duplicates are merged, and anything that looks like a secret is refused.

recall

Searches by meaning and by keyword, fuses the results, and ranks recent and often-used memories higher.

forget

Deletes a memory by its id.

Install

Checks the download's SHA-256, registers every agent it finds and fetches the embedding model.

01

Install

$ curl -fsSL https://raw.githubusercontent.com/hemanth090/agent-mem/main/install.sh | sh
02

Restart your agent

Then check the daemon.

$ ~/.agent-mem/bin/agent-mem status
03

Tell agents when to use it

$ ~/.agent-mem/bin/agent-mem install --instructions-only --write-instructions ./AGENTS.md

Questions

Does it save automatically?
No. An agent saves a memory only when it calls remember. The instructions block tells it when that is worth doing.
What leaves my machine?
Only the one-time model download from Hugging Face. There is no account and no telemetry.
Which agents are tested?
OpenCode, end to end. Claude Code, Codex CLI and Antigravity use the same server and get config entries in their documented formats, but have not been run in the real apps yet.
How do I delete memories?
Ask the agent to forget one by its id, or stop the daemon with agent-mem stop and remove the ~/.agent-mem folder.
